## 1.51.0 — 界面全面重做 + 运维功能补齐

### 界面（本次主线）

- **控件全部自绘**：按钮 / 输入框 / 下拉框 / 复选框 / 表格表头 / 滚动条 / 提示框，不再使用系统默认 Win10 外观
- **按钮统一三级**：Primary（主操作）· Secondary（次要）· Danger（危险），尺寸收敛为 32 / 26 两档；禁用态改为灰底灰字
- **图标改用 Lucide**（ISC 许可，可商用）：62 个图标 × 4 色 × 24/32px = 496 张，导航、按钮、代码生成控件共用一套
- 卡片统一 10px 圆角 + 中性描边；键盘焦点环可见；hover 有淡色反馈
- **新增实时流量曲线**：近 2 分钟，下行蓝线 / 上行绿线，纵轴自动取整；只在「网卡」页采样，离开即停
- **新增 Toast 提示**（右下角，3 秒消失）与按钮忙碌转圈
- 设备列表为空时显示引导空状态

### 功能

- 静态 IP 租约：同网段校验、异段提示、一键清空
- 配置备份导出 / 恢复：白名单校验、恢复前自动备份、属主校正
- 配置漂移检测、快照对比（逐文件 md5，输出新增 / 改动 / 删除）
- 设备上下线事件、流量日 / 月统计
- 诊断增强：traceroute（ICMP 被吞时自动走 TCP 443）、路径 MTU（TLS 握手交叉验证）
- 智能队列（cake）状态查询与实时读数

### 修复

- 图标放在子目录不被打包 → 改扁平命名
- `grayrouter-ctl.path` 2 秒轮询触发 systemd 启动频率上限 → `StartLimitIntervalSec=0`
- `sqm stats` 在 `set -u` 下 `WAN` 未绑定变量
- 快照 diff 的 `trap` 引用函数内 `local` 变量
- 备份脚本 `$HOME` 为空、备份目录不存在
- 恢复后 `/etc/grayrouter` 属主被改成普通用户
- 设备页空状态一直不显示
- 按钮样式名存实亡（103 处硬编码颜色）
