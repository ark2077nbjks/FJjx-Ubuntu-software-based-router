## 1.51.6 · 窗口缩放修复 + 布局一致性

这一版**只改面板**，路由脚本本体没有功能改动（`install.sh` 等不变，本机无需重装）。

### 修复
- **6 个页面无法滚动**：校园网 / 设备 / 流量 / 测速 / 连接 / 日志 的内容超出窗口后被裁掉，下半部分按钮**永远点不到**。在导航内容区统一包一层滚动容器，一次修复全部页面（以后新增页面也自动带滚动）
- **窗口变窄时按钮被裁**：11 处横向按钮行改为**自动换行**（WrapPanel），放不下就换行，不会消失
- **表格在窄窗口溢出**：多网卡路由表格列宽由固定像素（170/150/150/70）改为**弹性星号 + 最小宽度**

### 改进
- **左侧导航完整可见**：导航项高度 46px → **30px**，最小窗口 1120×640 也能容纳全部 15 项
- **导航分组重名**：分组「系统」改为 **「维护」**，避免与页面「系统」混淆
- **按钮尺寸统一**：高度五种混用（24/26/28/30/32）→ **全部 30px**；图标与文字间距六种 → **统一 6px**

### 参考
响应式布局按微软官方「响应式设计技术」的**「重新排列」**方案实现（小窗换行、大窗横排）。
