# 界面整合（B 方案）：风险、预案与回滚

> 目的：把 14 个页面合并为 11 个，同时保证「功能一个不丢、任一步可单独回滚」。

## 一、变更范围（P0/P1 已完成）

| 阶段 | 内容 | 触及文件 |
|---|---|---|
| P0 | 删重复入口（其他页日志按钮、设备页累计流量列） | `MainWindow.xaml` |
| P1 | 三个检测页 → 「诊断」三页签；「WiFi + 无线频段」→ 「无线」 | `MainWindow.xaml` / `.xaml.cs` |
| P2 | 连接页部署块改名、页面别名表 | `MainWindow.xaml` / `App.xaml.cs` |

远端（Ubuntu 端脚本）**不在改造范围**，除已有的 `grayrouter-ctl.sh` 白名单追加。

## 二、风险与预案

| 编号 | 风险 | 怎么发现 | 预案 | 回滚动作 |
|---|---|---|---|---|
| R1 | 页面塌陷 / 空白 / 控件重叠 | `--page=` 逐页截图 | 每次只改一页，改完立刻截图 | 从 `_bak_repo_1.50.1/` 取回该文件 |
| R2 | 离开页面后定时器没停（常驻轮询） | 任务管理器 CPU、面板日志刷新频率 | 合并页时保留原 `page == "xxx"` 分支判断 | 恢复原分支代码 |
| R3 | 功能被吞（按钮点了没反应） | 功能对照表逐条打勾 | 每页改前先列控件清单 | 恢复控件与其 handler |
| R4 | 老页面记忆失效（上次停在不存在的页） | 重启后页面空白 | 加别名映射表（旧名 → 新页） | 清空 `settings.ini` 里 lastPage |
| R5 | 编译失败（BAML 报错） | `dotnet publish` 报 error | 小步提交，单文件回退 | `git checkout -- <file>` |
| R6 | 图标缺失 / 空白图标 | 截图里图标位置空白 | 只用现有 155 个 PNG，不新画 | 换回原图标名 |
| R7 | 发版泄露隐私 | 逐字节脱敏扫描 | 截图不进仓库；文案不写真实 SSID/IP | 停止发布，重新打包 |
| R8 | 远端被误改 | `git diff` 只应含 Windows 端 | 改动范围写死在上面表格 | 远端脚本从 `Ubuntuflie/` 还原 |

## 三、备份策略

1. 每次改文件前：复制到 `_bak_repo_1.50.1/<文件名>.pre_<阶段>_<月日_时分>`（本机工作目录，不进仓库）。
2. 可执行文件：`shuju/app/NetPanel.exe.old_<阶段>_<时间>`。
3. 每个阶段结束打一个 git commit（本地即可），失败可 `git revert`。

## 四、回滚步骤（三层）

```text
① 只回退界面：把 _bak_repo_1.50.1/ 里对应文件拷回 src，重新 publish
② 只回退 exe：copy shuju/app/NetPanel.exe.old_* → NetPanel.exe
③ 回退全部源码：git checkout -- Windowsfile/src
```

任何一步都不涉及远端、不涉及网络配置，回滚不会断网。

## 五、验证清单（每阶段必跑）

- [ ] `dotnet publish` 零 error
- [ ] 11 页逐页截图，无空白 / 无重叠 / 无裁切
- [ ] 功能对照表全部打勾（原按钮 → 新位置）
- [ ] 真机连上软路由：状态、设备、流量、SQM 状态均能读到
- [ ] 面板日志无异常堆栈
- [ ] 发版前：exe + zip 逐字节脱敏扫描 0 命中
