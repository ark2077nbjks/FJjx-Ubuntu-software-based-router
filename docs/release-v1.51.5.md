## 1.51.5 · 多网卡路由 + 界面归位

这一版改的是**面板**，路由脚本本体没有功能改动（`install.sh` 等不变，本机无需重装）。

### 新增
- **多网卡路由**（网卡页）：列出网卡 / IP / 默认网关 / 跃点数 / 状态，一键实现「外网走热点、内网走网线」的分流
- 分流前把原跃点数记进 `data\routediv.json`，「恢复自动」按记录**精确还原**，不是简单设回 automatic
- **备份与恢复**（系统页）：导出配置备份 / 恢复配置 / 检查配置漂移 / 快照对比

### 改进（按「作用对象」重新分区）
- 「其他」页更名 **「关于」**，只保留面板自身信息（版本 / 路径 / 运行环境 / 项目地址）
- **内存优化** → 状态页**左栏（本机区）**；**版本更新** → 关于页；**自动备份** → 系统页
- 左侧导航新增 **「系统」分组**（日志 / 系统），不再散在末尾
- 系统页副标题标为「远端软路由 · …」、关于页标为「面板自身 · …」——明确每页改的是谁

### 修复
- **窗口变矮时左侧导航底部项被裁掉、点不到**：导航模板里的 `TabPanel` 加了 `ScrollViewer`，现在可滚动
- **`--page=sys` 启动参数无效**：补上系统页英文别名
