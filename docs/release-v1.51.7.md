## 1.51.7 · 状态页总览仪表盘

这一版改的是**面板**，路由脚本本体没有功能改动（`install.sh` 等不变，本机无需重装）。

### 新增
- **状态页顶部总览仪表盘**（参考 pfSense Dashboard widget / iKuai 系统概况）：一屏看全关键指标
  - 外网认证状态、软路由连接状态
  - 远端 CPU 负载（LOAD1 · 核数）、内存占用（MEM_PCT）、温度
  - 在线客户端数、并发连接数（conntrack）
  - 磁盘使用率、已运行时长
  - **网关延迟**：每次刷新对远端网关做一次 ICMP 探测，显示 RTT（不通时标红）
- **加载动画**：`Controls/Spinner` 接入智能队列状态读取（加载时转圈、结束或异常时收起）

### 说明
- 总览数据**全部复用现有远端采集**（`StatusGather` 的 `kvInfo`），不增加额外 SSH 请求；网关延迟是唯一新增的一次本机 ping
- 卡片用 `WrapPanel` 排列，窗口变窄自动换行
- 每张卡片标注清楚是**远端软路由**的指标，不混本机信息
