===== 网络面板 NetPanel =====

【两个版本，按需选】
  1. Windowsfile\NetPanel.exe          ＝ 轻量版（约 1.6 MB）
     需要电脑上装了 .NET 10 桌面运行时才能开。
     下载：https://dotnet.microsoft.com/download/dotnet/10.0 → Desktop Runtime

  2. Releases 里的 NetPanel-selfcontained.exe ＝ 自包含版（约 76 MB）
     运行库已经打进去了，拷到任何 Win11 双击就能开，不需要装任何东西。
     第一次开如果弹「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

【第一次用】
  1. 双击 NetPanel.exe（需要管理员权限，会弹一次 UAC）
  2. 进「连接」页，填软路由地址（可填多个，逗号隔开）和用户名
  3. 点「测试连接」，通了右上角显示「远端已连接」
  4. 之后「状态」「网卡」「设备」「流量」这些就都有数据了

【只能开一个】
  同时开两个会弹提示并退出——两个一起跑会把流量统计算两遍。

【资料都在这两个目录里】
  Windowsfile\src   Windows 面板的完整源码（C# / WPF，.NET 10）
  Ubuntuflie\       Ubuntu 那边的安装包与脚本（GrayRouter-1.1.0.zip 是打好的包）

【装到 Ubuntu 上】
  详见 README.md 的「快速开始（Ubuntu）」；也可以在面板「连接」页
  上传 GrayRouter-1.1.0.zip 后点「开始部署」。

【数据写在哪】
  exe 旁边的 data\ 目录：日志、导出的 CSV、窗口位置、连接设置、采样记录、
  加密后的账号。设置集中在 data\settings.ini（中文注释，记事本可直接改）。
