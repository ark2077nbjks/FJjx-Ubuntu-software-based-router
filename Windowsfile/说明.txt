===== connectinternet 使用说明 =====

【目录结构】
  01-当前在用\       现在要用的脚本都在这
  02-备份-20261024软路由改造前\   改造前的原版（别动）
  03-历史版本\       更早的旧版本

【01-当前在用 里的五个脚本】
  0-查看状态.bat              看 软路由 现在什么模式、通不通、机器人在不在跑
                              自动找地址，免密码；想看防火墙规则再输一次密码
  1-热点模式-启动机器人.bat      固定连 （热点地址）（软路由 在热点模式时用）
  2-软路由模式-启动机器人.bat    固定连 （软路由地址）  （软路由 在软路由模式时用）
  3-自动探测-启动机器人.bat      两个地址都试，自己找（推荐，不确定模式时用这个）
  4-自动探测-连接终端.bat      只开一个 SSH 终端，不启机器人（排查用）

  ★ 机器人是跟着窗口走的：窗口关掉，bot 就停。

【两种模式怎么对应】
  热点模式   = 主力机认证校园网 + 开移动热点
               软路由 连这个热点 → 地址 （热点地址）
               适合：主力机正在用的时候

  软路由模式 = 软路由 认证校园网，有线进无线出
               软路由 开热点 Gray-Router（密码 GrayRouter2026）
               主力机连它 → 软路由 地址 （软路由地址）
               适合：想让 bot 常驻、其它设备也能上网

【连不上怎么办】
  1-热点模式 报「连不上 （热点地址）」：
     在 软路由 桌面双击「3 模式切换」→ 输入 1 → 回车 → 输密码

  2-软路由 报「连不上 （软路由地址）」：
     在 软路由 桌面双击「3 模式切换」→ 输入 2 → 回车 → 输密码

  两个都连不上：软路由 没开机，或者两台机器之间网络断了。

【两条铁律】
  1. 同一个账号同一时刻只能有一台设备认证校园网。
  2. 软路由模式下，主力机的「以太网」必须禁用
     （设置 → 网络和 Internet → 高级网络设置 → 网络适配器 → 以太网 → 禁用），
     否则校园网会看到两个 MAC。

【软路由 侧对应图标】
  1 强制回滚到热点   2 强制重建软路由   3 模式切换
  4 查看状态(完整)   5 查看状态免密     6 加固伪装

【谁起的，关哪个窗口】
  0-查看状态 里「启动来源」那一行会写清楚：
    · 主力机 SSH 起的     -> 关掉主力机上那个 bat 窗口，bot 才停
    · 软路由 本机窗口起的 -> 关掉 软路由 桌面那个窗口，bot 才停
  另一个方向只会报 [BUSY]，不会抢。

【网络面板 NetPanel（桌面软件）】
  启动：双击本目录里的「网络面板.lnk」
  程序：shuju\app\NetPanel.exe      源码：shuju\src\      数据：shuju\data\
  第一次启动会弹 UAC（要管理员权限，因为要能启停网卡），必须点「是」。

  左侧六栏目（v1.0）：
    状态   本机网卡 / IP / 当前 WiFi / 校园网通不通
           + 软路由 的模式、机器人进程、UA3F（每 15 秒自动刷新）
    网址检测 填域名点「检测」，或一行一个批量；也可点下面 10 个常用网站直接测
           输出 状态码 + DNS/连接/TLS/首字节/总耗时，能看出是 DNS 慢、连接
           不通还是被墙（TLS 握手超时/被重置）；上次填的网址会自动记住
           常用站点分三组，点一个就测它：
             国内常用：百度 B站 知乎 淘宝 QQ 微博 网易 京东 阿里云 知网
             国外常用：YouTube Google X Facebook Instagram 维基 Reddit
                      Discord Twitch Netflix ChatGPT Steam社区
             GitHub 相关：github.com / api / raw / gist / codeload / github.io
                      / objects.githubusercontent.com
           「测全部常用」一次跑 29 个，约 12 秒
    网卡   启用 / 禁用本机网卡
           每次操作先弹确认框，默认「否」；禁用 WLAN 会立刻断网（有专门警告）
           支持热插拔：插上/拔掉网卡（含 USB 转网口）8 秒内提示
           「检测到新网卡：xxx」并自动刷新列表；没驱动时系统不会列出它，
           那种情况去「设备管理器」看（黄色感叹号）
    WiFi   已保存的网络可以直接连接（不需要位置服务）
           要扫周围的新网络，必须开「位置服务」+ 管理员（Windows 11 系统限制，
           任何软件都绕不过）；页面上有「打开位置设置」按钮
    游戏延迟  CS2 亚服线路检测：发 20/50/100 个 ICMP 包，出延迟 / 抖动 / 丢包
           预置：Valve 香港（26ms，打 CS2 走这里）/ 新加坡（315ms，别连）/
                 Steam 商店 / 国内对照；也能在右边填任意服务器 IP
           结果给评级：极佳 / 良好 / 勉强 / 不适合（丢包 >3% 直接判不适合）
    测速   7 个测速源可选（清华 / 腾讯 / 华为 / 南大 / 上海交大 / 阿里 / Cloudflare）
           连接数可选 1 / 2 / 4 / 8（默认 4）：国内镜像单连接常被限速，多连接累加更接近真实带宽
           时长 10 / 20 / 30 秒，边测边画 XY 折线图
           显示当前、平均、峰值、已下载、延迟
           注意：20 秒 4 连接大约消耗 60~70 MB 流量（按 25 Mbps 估）

    日志   看运行日志（最新在上面），可刷新 / 清空（旧的备份成 app.log.1）/ 打开目录
           网址检测可「导出」成 csv（excel 直接打开，中文不乱码）
           测速每次结果自动追加到 data\speed.csv
           游戏延迟可选「连测 1/3/5 次」，多轮会给出各轮数值和平均值

    设备   扫一遍本网段，看有哪些设备连着
           自动填本机所在网段（例如 192.168.50.0/24），点「扫描」约 10 秒
           两条来源：本机 ping + ARP 表；配了软路由的话再加上它的邻居表和 DHCP 租约
           列：IP / MAC / 厂商 / 名称 / 来源 / 状态 / 延迟，自己的机器标「这台电脑」
           「导出 CSV」存到 data 目录

    连接   连接远端软路由（SSH），并能把部署包推过去
           填：地址 / 用户名 / 端口 / 登录方式（自动·只用密钥·只用密码）
           地址可以填多个，用逗号隔开（例如 192.168.50.1,192.168.137.232），会自动选第一个通的
           「测试连接」→ 立刻告诉你密钥能不能用、失败原因是什么
           「打开终端」→ 弹一个黑色命令行窗口直接连上去，可以在里面敲命令
           「选择 zip…」选 GrayRouter 部署包 →「上传到远端」推到 /tmp/grayrouter-upload
           「开始部署」→ 弹一个终端窗口，在里面完成安装（sudo 密码在那个窗口输）
           密码不保存、不经过本程序

   注意：右上角显示「远端已连接 / 未连接」，就是 SSH 通不通的结果。

  数据目录 shuju\data\
    app.log           运行日志（出问题先看这个）
    last-status.txt   最近一次刷新的状态快照
