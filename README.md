# 校园网软路由一体包

把一台 Ubuntu 小主机变成**能共享校园网的软路由**，并配一个 Windows 桌面面板来查看状态、管理网卡、测速、部署。
整套东西**双击安装、中文界面、不需要命令行经验**。

> 适用场景：宿舍/实验室只有一条需要网页登录（深澜 srun 一类）的校园网，想把网络分给手机、平板、第二台电脑。

---

## 依赖说明

- **Windows 面板**：发布的是**自包含版**，不用另装 .NET，拷过去双击就能开。
- **Ubuntu 安装包**：第一步自动自检 NetworkManager / iproute2 / nftables / iw，缺什么直接给 apt 命令。

## 它能干什么

| 能力 | 说明 |
|---|---|
| 一键变软路由 | 有线接校园网当 WAN，无线开热点 `Gray-Router` 当 LAN，自动 NAT + 转发 |
| 一键回滚 | 恢复到装机前的网络设定，热点的有线口重新自动连接 |
| 开机自启 | 断电重启后自动回到软路由状态（可关） |
| TTL 伪装 | 让下游设备的 TTL 看起来来自本机，绕开「多设备共享」检测 |
| 网络体检 | 只读检查：网卡、AP 能力、出口类型、端口占用、拓扑可行性 |
| Windows 面板 | 状态 / 网址检测 / 网卡 / WiFi / 游戏延迟 / 测速 / 连接部署 / 日志，九个栏目 |
| 远程部署 | 面板里填个 IP 和用户名，就能把部署包推到那台 Ubuntu 上一键装好 |

**不做的事**：不帮你自动登录校园网（登录/注销请用学校门户或 srun 客户端手动做）；不做 HTTPS 解密（装 CA 太麻烦，也不安全）。

## 硬件要求

| 项 | 最低 | 说明 |
|---|---|---|
| 主机 | 任意 x86_64 小主机（J4125 一类够用） | 4 核 + 4G 内存跑得很轻松 |
| 有线网卡 | 1 个 | 接校园网 |
| 无线网卡 | 1 个，且**支持 AP 模式** | 用来发热点；体检脚本会告诉你支不支持 |
| 系统 | Ubuntu 22.04 / 24.04 / 26.04 | 用 NetworkManager 管网络 |

无线网卡不支持 AP？那就只能走「有线全接交换机」的老办法，本包帮不上。

---

## 三种拓扑（安装时自动探测，你只需选）

| 拓扑 | 网卡 | 说明 |
|---|---|---|
| **A** | 有线 = WAN，无线 = 热点 | 最常见，一台机器搞定 |
| **B** | 无线 = WAN（连别人的热点），有线 = LAN | 没有 AP 能力的无线网卡时用 |
| **C** | 有线 = WAN，第二个有线 = LAN | 双网口工控机，接交换机分给多台设备 |

安装程序会自己枚举网卡、判断哪个有线哪个无线、能不能发热点，冲突的地址会自己换掉，不用你手填。

## 快速开始（Ubuntu）

1. 从 **Releases** 下载 `GrayRouter-<版本>.zip`（当前 1.50.1），拷到 Ubuntu 上右键「解压到此处」。
2. 双击 **`GrayRouter-安装.desktop`**（第一次可能要点「标记为可信」或右键「允许启动」）。
3. 向导里选拓扑、填热点名和密码 → 确认 → 输一次 sudo 密码。
4. 装完手机/电脑连 `Gray-Router` 就能上网。

命令行等价写法：

```bash
bash grayrouter-doctor.sh                 # 先体检（只读，不改任何东西）
sudo bash install.sh                      # 交互安装
sudo bash install.sh --help               # 看所有参数（静默安装用）
```

## 从 Windows 面板部署（一键）

> v1.35 起部署包已经**内置在 exe 里**，点「开始部署」会弹出部署窗口，全程不用碰终端 —— 只在面板里填两次密码（都在这台 Windows 上输）。

### 先决条件（Ubuntu 上做一次）

```bash
sudo apt update && sudo apt install -y openssh-server
sudo systemctl enable --now ssh
```

两台机器要能互相访问（有线直连、同一个路由器、或 Ubuntu 先连上你的热点都行）。

### 三步

1. **连上 Ubuntu** — 面板「连接」页填地址和用户名，点「测试连接」。
   - 地址可填多个，逗号隔开（如 `192.168.1.23,192.168.50.1`），自动挑第一个通的
   - 不知道地址点「自动探测」：上次地址 → 默认网关 → ARP 邻居 → 同网段 .1
2. **点「开始部署」** — 弹出窗口里填 6 项：拓扑（A/C）· 热点名 · 热点密码 · LAN 网关 · SSH 密码 · sudo 密码。
3. **再点窗口里的「开始部署」** — 进度条按 7 步走，日志实时刷，最后给 9 项自检结果（√/×）。

### 演练模式（强烈建议先跑一次）

勾上「演练模式」= 安装脚本加 `--dry-run`：**只探测硬件、打印计划，不写任何文件、不改网络**。用来确认链路通、参数对，再关掉演练做真装。

### 出问题怎么定位

| 现象 | 面板会显示 | 原因 |
|---|---|---|
| 连不上 | `SSH 认证失败：用户名或密码不对` | 密码错 / 没开 sshd |
| sudo 不认 | `sudo 密码不对`（2 秒内） | sudo 密码与 SSH 密码不同 |
| 装到一半断了 | `安装过程中连接断开…等它回来` | 正常现象（NetworkManager 重启），等最多 3 分钟自动续 |
| 自检有 × | 逐项列出「名称 — 说明」 | 按最后一句提示处理 |

部署日志同时写进 `data\app.log`（前缀 `[部署]`），事后能查。

### 密码处理

- 两个密码只在本机内存，**不落盘、不进日志、不进命令行**
- sudo 密码写进远端 `600` 临时文件喂给 `sudo -S`，跑完立即删除
- 安装参数（SSID/密码/LAN 网关）写进远端临时脚本（600），装完随临时目录一起删

### 手动方式（仍然保留）

「上传到远端」→「打开终端」→ 在终端里 `sudo bash install.sh`，老流程一样能用（适合你想逐项确认的情况）。

### 装完之后

6. **连新热点** — 电脑/手机 Wi-Fi 连 `Gray-Router`（密码就是部署窗口里填的那个）。**这一步连接会断一下是正常的**：AP 一起来，Ubuntu 的有线口被 netplan 接管，原来的有线/旧 WiFi 链路就不通了。
7. **认证校园网** — 面板「校园网」页填账号、密码、运营商（联通/移动/电信/校园网），点「登录」。密码用 Windows DPAPI 加密存在本机，认证是在 Ubuntu 上执行的。

### 三个坑

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 部署到一半 SSH 断了 | AP 起来了，旧链路被接管 | 连 `Gray-Router`，面板「连接」页把地址改成 `192.168.50.1` |
| 校园网登录报 `user_type` 错 | 运营商选错（联通/移动/电信） | 「校园网」页换一个运营商再登 |
| 两台机器互相踢断线 | 校园网一号一设备，两台同时在线认证 | 先在其中一台上注销，另一台再登 |

### 面板上还能做什么（和部署无关的）

装完之后这些都不用再碰终端：

- **状态** — 看模式（软路由 AP / 热点客户端）、WAN/LAN、出口 IP、伪装层、看门狗
- **设备** — 扫本网段有哪些设备（IP/MAC/名称/连接），可导出 CSV；每行可**拉黑/解除**（按 MAC，nft 双链丢包），顶部「全部解除」，另有**每设备流量**（上行/下行，读 `iw station dump`）
- **网卡 / WiFi / 测速 / 流量 / 游戏延迟 / 网址检测 / 代理检测 / 日志**
- **看门狗** — 一键装到 Ubuntu：每分钟检查无线是不是「假在线」，默认只记录，可切成自动重启 AP
- **软路由模式** — 切到软路由 / 回滚到热点 / 加固伪装（首次点会提示装一次权限助手）

## 伪装层（默认就装，客户端零配置）

安装时自动装好 **UA3F**，它在软路由上做两件事，**不需要在任何手机/电脑上装证书**：

- **IPID 重写** —— 改 IP 头里的 16 位序号，让同一账号后面的多台设备看起来像一台（对 HTTPS 同样有效）
- **ua3f.service** 常驻，开机自启；引流规则用独立 nft 表 `ip gray_ua3f`（tproxy → 1080）+ 策略路由表 457

不做的事（明确不做的）：**不开 MitM、不解密 HTTPS、不装任何客户端证书**。

相关命令：

```bash
systemctl status ua3f                     # 服务在不在跑
sudo bash /opt/grayrouter/bin/ua3f-rules.sh status   # 规则/策略路由/1080 监听
sudo bash /opt/grayrouter/bin/ua3f-rules.sh clear    # 想临时关掉伪装
```

`router-down.sh` 会把规则一起清掉；`uninstall.sh` 会停服务并删规则表。

卸载：

```bash
sudo bash uninstall.sh -y                 # 全部清理干净
```

## Windows 面板（可选，但好用）

面板是单文件程序（从 **Releases** 下载 `NetPanel.exe`，仓库不再存构建产物），双击即用（会请求管理员权限，因为要读网卡和 WiFi 信息）。需要 **.NET 10 桌面运行时**；不想装运行时的，可以自己 `dotnet publish -r win-x64 --self-contained true` 出一个自包含版本。

十四个栏目（v1.35）：

- **状态** — 本机网卡/出口 IP/联网判定（**虚拟网卡可展开**，默认收起），右侧显示远端软路由的状态（地址/模式/运行时长/WAN/LAN/客户端/出口/**伪装**/**守护**/远端网口清单）；右上角 **一键诊断**，9 项逐条查（本机→网关→DNS→204→出口 IP→强制门户→软路由→远端出口→延迟），哪一层断就停在哪一层并给出结论，**同时给出「可能原因」和「怎么解决」**，结果可复制
- **看门狗** — 状态页可一键装到远端（一次 sudo 密码）：每分钟检查「AP 有 IP + 有设备 + 3 分钟零流量」= 假在线；默认**观察模式**只记录，可切**自动执行**（检测到就重启 AP 连接，连试 3 次无效停手）；另有 **重启 AP** 按钮（点一下 60 秒内生效，不用密码）
- **软路由模式** — 状态页底部卡片：**切到软路由** / **回滚到热点** / **加固伪装**，每个都带前提确认；首次点会提示装远端权限助手（一次 sudo 密码，之后全免密），助手只认这三个命令
- **校园网** — 填账号/密码/运营商（**中国联通 / 中国移动 / 中国电信 / 校园网 / 自定义**）后直接登录、注销、查在线状态；密码用 Windows DPAPI 加密存在本机，认证在 minipc 上执行
- **网址检测** — 29 个常用站点分组测速（DNS/连接/TLS/首字节），可导出 CSV
- **网卡** — 列出物理网卡，可启用/禁用（**三次确认，默认否**）；被系统禁用的设备也能正确识别
- **设备** — 扫本网段有哪些设备：IP / MAC / **名称** / **连接**（无线 2.4G -54dBm · 已连 12 分钟 / 有线 · 1000 Mbps / 网关 · 本机直连）/ 在线 / 延迟，可导出 CSV；**网段按当前网络自动填**，快速模式只读邻居表 + 每台 1 个轻 ping（最多 40 台），另有 **深度扫描**（254 个地址 × 1 个 ICMP，16 并发、间隔 30ms，约 15 秒，用于找出不在邻居表里的静默设备）；名称取软路由 dnsmasq 的反向记录并去掉随机后缀（`android-132378065a` → `android`），查不到时按类型显示
- **WiFi** — 已保存网络的连接/断开
- **游戏延迟** — ping 游戏服务器，给延迟/抖动/丢包评级，可选连测 3 次取平均
- **测速** — 14 个测速源（清华/腾讯/华为/北大/南大/上交/浙大/华科/兰大/东北/北外/阿里/Cloudflare 等）+ 自定义地址，1~8 连接可选；安兔兔式仪表盘 + **下载蓝/上传绿双线图**，测速源失败自动换源，结果手动导出
- **流量** — 每 15 秒采样一次，按小时画 24 根柱（绿=下行/蓝=上行），**底部整点时间轴（00:00~23:00，标签随宽度自动疏密）+ 每小时淡竖线**，今天/昨天/近 7 天合计 + 每网卡占比
- **连接** — 地址可手填（多个用逗号）也可点「自动探测」：按 上次地址 → 默认网关 → ARP 邻居表 → 同网段 .1 的顺序找，最多探 12 个、每个 400ms、并发 4，找到后用密钥跑 `hostname` 验证再自动填好；进页面时还会静默探一次。另有测试 SSH、打开交互终端、上传部署包、一键部署
- **代理检测** — 三层：本机代理环境（10 秒）、出口身份（60 秒）、延迟基准（60 秒）；识别系统代理/WinHTTP/环境变量/TUN 网卡/常见代理进程/本地监听端口
- **日志** — 看程序日志，可刷新、清空、打开目录
- **其他** — 关于本软件、常用文件（日志/设置/导出目录/卸载程序）、运行环境、项目地址；**内存优化**（同 PCL2 百宝箱：清工作集 + 刷修改页 + 清待机列表，不杀进程）；**日志保存位置**可改（剪切语义，源文件不保留）
- **无线频段** — 软路由 AP 的实时射频状态（每 2 秒刷新，只在该页生效）：频段 / 信道 / 带宽 / 发射功率 / SSID / 客户端数，每台设备显示 MAC、信号、上下行速率、空闲时长；下方可**切换频段与信道**（下拉里只列实测可用信道，自动档 5G=36、2.4G=6），切换前先上 150 秒「死手保险」，5G 起不来自动回滚，重启后回到 netplan 的 2.4G 配置。
- **版本更新**（在「其他」页）— 查 GitHub Release、比较版本、下载并自替换重启；下载大小校验不过就拒绝替换。

另有两个便利项：

- **托盘常驻** — 点 × 默认缩到托盘继续采样（右下角蓝色路由器图标，双击打开）；右键可改成「直接退出」，也能开关断网提醒（60 秒一次心跳，掉线/恢复弹气泡）。
- **单实例锁** — 同一时间只允许开一个面板，避免流量重复统计。
- **界面图标** — 153 个图标取自统一图标库；十三个导航、各页按钮、状态圆点（绿/黄/红随状态变色）、输入框前缀都有图标。

数据都写在 exe 旁边的 `data\` 目录里（日志、导出的 CSV、窗口位置、连接设置、采样记录、加密的校园网账号）；设置集中在 `data\settings.ini`（中文注释，记事本可直接改）。

## 设备管理（拉黑 / 流量）

面板「设备」页扫描出局域网设备后，每行右侧有「拉黑」按钮，顶部有「全部解除」。

- **拉黑按 MAC，不按 IP** —— 设备换 IP、重连 DHCP 都逃不掉。规则写在 nft 表 `inet gray_dev`，`forward` 和 `input` 两条链都丢包：设备照样连着 WiFi，但完全上不了网。
- **解除**即时生效，`全部解除` 一次清空。
- **流量列**读的是内核 `iw ... station dump` 的 `rx/tx bytes`（和 OpenWrt 同一套数据源），不走自己数包，最准也最省 CPU。
- 黑名单存在 `/etc/grayrouter/devices.json`，由 `grayrouter-devices.service` 开机恢复。

装一次（Ubuntu 侧，需要 sudo）：

```bash
sudo bash Ubuntuflie/install-devmgr.sh
```

它会把 `bin/grayrouter-devices.sh` 装到 `/usr/local/bin/`、装好开机恢复单元、给遥控助手 `grayrouter-ctl.sh` 的白名单加上 5 条设备命令（会先备份原文件）。

命令白名单只接受 `aa:bb:cc:dd:ee:ff` 形式的参数，别的格式直接拒绝 —— 面板没法借这条通道执行任意命令。

## 常见问题

**装完连上热点但没网？**
先确认校园网已经在这台机器上认证过（`curl -I https://www.baidu.com` 能通）。软路由只负责转发，不负责登录。

**热点搜不到？**
网卡不支持 AP 模式，或者被 `wpa_supplicant` 占了。跑 `sudo bash bin/grayrouter-info.sh` 看 `SSID` 那行是不是空。

**回到原来的状态怎么办？**
双击「卸载」，或 `sudo bash uninstall.sh`。有线口会自动恢复自动连接，网络设置里不会留下垃圾。

**TTL 伪装一定要开吗？**
看学校。多数校园网按 IP 数或按 MAC 数限制，不查 TTL。被检测到共享再开就行。

**面板显示「远端未连接」？**
SSH 没通。检查地址对不对、那台机器有没有开 SSH（`sudo systemctl status ssh`）、用户名是否正确。密钥登录最省事：把公钥放进对端 `~/.ssh/authorized_keys`，面板就会显示「密钥登录可用」。

**要不要在这台机器上装 Python / Docker？**
不用。整个包只有 bash + NetworkManager + nftables，系统自带。

## 安全与隐私

- **不保存任何密码**：面板连接软路由时，密码要么走 SSH 密钥，要么在弹出的系统终端窗口里手输，程序本身不接触。
- **不内置任何人的地址**：所有 IP、用户名、SSID 都在安装时填写，仓库里没有个人配置。
- **不上传数据**：没有任何遥测、没有外部上报，唯一的网络行为是你主动触发的测速和 ping。
- **改动前先备份**：安装脚本会把原配置备份成 `*.bak_时间戳`，卸载时按备份还原。
